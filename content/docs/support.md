goilerplate is free and open source. Help happens in public, where the next person finds it too.

## GitHub

Use [GitHub Issues](https://github.com/axadrn/goilerplate/issues) for CLI bugs, documentation problems, and feature requests. Include the CLI version, command, expected result, and smallest useful reproduction.

Pull requests are welcome. Contributions come in under the license of the files they change.

Never post credentials, tokens, private source code, or security vulnerabilities in a public issue.

## Security reports

Report a vulnerability [privately on GitHub](https://github.com/axadrn/goilerplate/security/advisories/new).

Replies are best effort. There is no guaranteed response time.

## Boundaries

There are no calls, custom development, deployment management, production incident response, or debugging of application-specific code. A bug that reproduces in a fresh goilerplate project belongs on GitHub. Product work built on top of that project belongs to its owner.
