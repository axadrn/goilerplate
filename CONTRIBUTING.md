# Contributing

Thanks for helping. Read `AGENTS.md` for how the code is built and tested.

Pull requests are welcome. For anything bigger than a fix, open an issue
first so we can agree on the approach. Your contribution comes in under the
license of this repository.

## Commits and releases

Commits follow [Conventional Commits](https://www.conventionalcommits.org):

```
feat: a teams page in the starter
fix(cli): keep the module path on update
docs: how to deploy with ops
```

`feat`, `fix`, `docs`, `chore`, `refactor` or `test`, an optional scope, a short first line. Release notes list what is new, what is fixed and how to upgrade.

## Never commit

Secrets, `.env` files, customer data or private details.
